Prompt Animasi Seri 44 Indikator (Versi Kit)
Dokumen ini berisi prompt untuk agen AI pembuat animasi. Setiap prompt indikator lengkap dan berdiri sendiri. Salin satu prompt utuh, mulai dari judul “Prompt Animasi Indikator” sampai bagian K, lalu berikan ke agen.
Ada satu prompt yang berbeda, yaitu Prompt 00. Prompt ini bukan aturan umum. Isinya pekerjaan satu kali untuk menambahkan format video baru dan modul kuis ke kit. Kerjakan Prompt 00 sekali sebelum prompt indikator mana pun, karena format 21 detik yang ada di kit sekarang (gejala, cermin, langkah) tidak cocok dengan struktur baru.
Struktur setiap video:
Bagian 1, Gejala. Label “GEJALA”.
Bagian 2, sebab. Label “KENAPA FENOMENA TERSEBUT MASIH TERJADI?”.
Bagian 3, Ikhtiar atau Pandangan. Label “IKHTIAR HMI EVIDENCE” atau “PANDANGAN HMI EVIDENCE”.
Bagian 4, Kuis. Label “AYO IKUTI KUIS SEBERAPA EVIDENCE KOMISARIATMU”.
Bagian 5, Kartu akhir.
