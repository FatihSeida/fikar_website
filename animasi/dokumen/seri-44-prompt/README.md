# Prompt Seri 44 Indikator untuk Agen AI

Setiap berkas indikator-01.md sampai indikator-44.md adalah prompt lengkap yang siap disalin dan diberikan ke agen, satu prompt untuk satu video. Tidak perlu dokumen lain.

Saran urutan: kerjakan lebih dulu 01, 05, 14, 18, 24, dan 36 (satu dari setiap dunia visual) untuk memastikan gaya visualnya sudah sesuai, lalu lanjutkan sisanya.

Indikator yang perlu ditinjau manusia sebelum tayang: 09, 19, 21, 22, 29, 34, 39, dan terutama 40.

Berkas 00-SPEK-BERSAMA.md dan 00-PROMPT-TEMPLAT.md tidak dipakai lagi dan boleh dihapus.
